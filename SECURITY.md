# Security policy

wayland-mcp gives an AI agent screenshots of, and input into, the desktop it
runs on. Run it only with MCP clients you trust. Prefer sandbox targets
(`sandbox_start`) for unattended work, and leave `WAYLAND_MCP_PORTAL` unset
unless you want the agent to control your real GNOME or KDE session.

To report a vulnerability, use GitHub's private vulnerability reporting on
this repository (Security tab, "Report a vulnerability") instead of opening a
public issue.
